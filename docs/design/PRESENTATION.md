# Визуальный, звуковой и интерфейсный контракт (G1 DRAFT)

## Художественное направление

Уютная научная фантастика без фотосюрреализма: маленькие лунные купола, компактные инженерные устройства, читаемые сверху роботы и грузы. Свет — тёплые янтарные окна, холодная лунная поверхность, выразительная зелень оранжереи. Визуально различать **колонию** (живой изометрически-плоский вид) и **диспетчерскую** (строгая плоская логическая сетка). Приоритет — ясность игрового состояния, а не детализация иллюстраций.

Рабочие цвета: лунный сине-серый, тёмно-синий фон, пыльный оранжевый, мягкий бирюзовый/зелёный, светлые надписи. Это направление, не утверждённые токены. Не копировать чужие изображения, UI, фирменные элементы или шрифты. Каждое итоговое медиа должно иметь отдельную provenance/rights запись и проверку реальных пикселей.

## Различимость

| Сущность | Первый сигнал | Резервное кодирование |
| --- | --- | --- |
| Контейнер с водой | Бирюзовый | Капля |
| Кислород | Светло-зелёный | Символ O₂ |
| Детали | Янтарный | Гайка |
| Стрелка | Поворотный визуальный рычаг | Стрелка-направление |
| Заряд / опасность | Сегменты батареи | Число/значок + текст |
| Конфликт/ожидание | Пульсирующий контур | «Путь занят» / статус |

Не полагаться на один цвет или слух. У игрока должна быть возможность различать виды грузов без подписи длиной с половину экрана.

## UI

Сверху: название контракта, цели, батареи, прогресс доставок; центр: карта; снизу: инструмент/пауза/шаг/повтор. В colony mode: карта модулей, доступные площадки, энергетическая мощность и материалы, контракты. «Запуск» всегда явно отличать от «Продолжить». Ввод и логика симуляции не зависят от frame time.

Mobile priority: проектировать для портретного экрана и проверять **320×568, 390×844, 768×1024**, дополнительно **667×375 landscape**; desktop **1440×900**. Размеры — тестовые, не готовые доказательства. Для касания целиться минимум в 44×44 CSS px интерактивной области и не размещать важные переключатели под панелью. Не использовать обязательные hover-подсказки.

## Звук и обратная связь

Мягкие механические клики, короткий успешный сигнал, отчётливое предупреждение конфликта без резких громких звуков. Музыка — опциональная, без обязательной лицензируемой чужой мелодии. Браузерное аудио запускается только после разрешённого действия, обрабатывает autoplay denial, паузу и жизненный цикл SDK. Отсутствие звука не блокирует прохождение.

## Asset gates

На G1 ассеты **не изготовлены**, references (если появятся) служат только мудбордом; никаких фальшивых «изображения готовы». На G3 требуются реальные исходные файлы, licence/provenance, проверка размеров, читаемости, шрифта, runtime-соответствия и мобильных экранов; на G6 — совпадение состава реально упакованного билда с ведомостью источников.
