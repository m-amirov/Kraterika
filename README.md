# Кратерика

2D логистическая головоломка с развитием лунной колонии.

**Состояние:** G1 — Game Design / repository bootstrap. Полная игра и платформенный экспорт ещё не реализованы.

Игрок организует доставку грузов, управляет роботами и механизмами, получает ресурсы и развивает функциональную колонию. Формат: **вариант B — логистика + строительство**, без экономики с десятками ресурсов и без обязательного ожидания реального времени.

Документы и процедуры инициализации появятся в следующем коммите.

Репозиторий: https://github.com/m-amirov/Kraterika
